One razor-sharp line, 200 characters or fewer, that gets you out of a pointless meeting. An AI judge pairs excuses head to head and crowns the biggest laugh.

**The entry:**

> Sorry, I can't make it — I'm already in a meeting about this meeting, and that one actually has an agenda.

## How it works

`main.ts` (Node 22) writes the single excuse line to `/output/entry.txt` (106 characters, UTF-8).

```sh
node main.ts
```
